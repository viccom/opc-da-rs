## OPC Foundation — IDL Specifications

The frozen bindings were generated from OPC Foundation Interface Definition
Language (IDL) files (`opcda.idl`, `OPCComn.idl`). These specifications
define the OPC Data Access 2.05a/3.0 COM interfaces.

- **Source**: [OPC Foundation](https://opcfoundation.org/)
- **Specification**: OPC Data Access Custom Interface Standard
